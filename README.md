# D&S Auto Center

OS no celular para dois sócios: o mecânico levanta serviço e peças, o vendedor cota e compra, o cliente recebe um PDF.

## Local

1. `npm install`
2. Copie `.env.example` para `.env.local` e preencha `VITE_SUPABASE_URL` e a chave pública (`VITE_SUPABASE_PUBLISHABLE_KEY` ou `VITE_SUPABASE_ANON_KEY`). Nunca coloque service role no front.
3. `npm run dev`
